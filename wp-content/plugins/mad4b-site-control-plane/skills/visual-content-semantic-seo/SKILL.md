# MAD4B Visual Content & Semantic SEO Intelligence

One reusable strategic skill, not separate prompts for every tourism product or provider. PHP runtime: MAD4B_SCP_Visual_SEO_Strategy. Skill guidance is NOT authorization to mutate WordPress.

## Evidence order

1. Exact enrolled Site Profile, Brand Context and review policy (provisional does not mean approved).
2. Actual post, itinerary, linked destination taxonomy and WPML language family.
3. Observed visual content and representation, bound to exact image SHA-256.
4. Active WordPress, JetEngine, WPML and Rank Math provider field definitions.
5. Existing original Content Jobs, versioned Artifacts and approval receipts.

## Strategy composition

- Destination Relevance: use the real experience destination from taxonomy naturally in image Alt Text; no invented geographical context.
- Visual Truthfulness: distinguish illustration/composite from photograph; a place mentioned as excursion context is not a claim where the image was taken.
- Multilingual SEO: give each WPML locale an accurate, natural Alt proposal bound to its Attachment.
- Brand Alignment: inherit company tone, verified Brand Context evidence and review state.
- Media Role: use discovered Featured, Gallery, Grid and Vertical field semantics. V1 mutations support Featured Alt proposals only; other role inspection is read-only.
- Search Intent: useful experience-led wording, without keyword stuffing.
- Provider Adaptation: respect WPML translation modes, JetEngine field registration, WordPress Meta Registry and existing Rank Math metadata.

## Hierarchy

Global Strategy > Company Brand > Content Type > Destination Taxonomy > Media Field > Language/Market.

Version 1 resolves the six layers and records their evidence. Where no stored scoped override exists, override_applied=false. A governed persisted override writer is not part of v1.

## Execution contract

1. Use WP-CLI visual-strategy inspection to resolve source and providers.
2. Supply structured observed objects, representation, image SHA-256, gallery SHA-256, grounded destination slug and localized drafts.
3. Validate all WPML locales and actual image bytes, truthful representation, taxonomy destination and semantic content.
4. Use signed Host media_strategy operation and exact Artifact Append grant to create a new, immutable SEO QA Artifact. Supersede the older version without removing it.
5. Route through the effective human_only, human_and_ai or ai_only Review Policy. Strategy proposals do not approve themselves.
6. Perform any actual Alt change, Gallery replacement, cache invalidation and frontend verification ONLY via a later separately authorized Apply action.

## Acceptance and failure modes

Reject a destination not in taxonomy; a draft missing the validated destination; an illustration advertised as a photograph; outdated media SHA; missing WPML locale; unsigned mutation; or superseded expected Artifact. Exact duplicate signed requests return the current Artifact.

Always distinguish review-ready, review-approved and applied-and-verified. Keep evidence for actual live deployment separate from a source Git commit.
