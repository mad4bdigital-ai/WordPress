# Composite Media Integrity — MAD4B

The read-only `mad4b-media-composite-integrity.php` Configuration Jobs provider inspects JetEngine gallery and repeater definitions for all registered public post types and taxonomies. It only scans objects with nonempty stored fields, using capped indexed meta lookups, not frontend requests. For galleries it compares the **raw database value** with the effective WordPress metadata, because dynamic filters can make a legacy external URL appear local. Supported representations: comma-separated URL strings; native ID arrays; JetEngine `[{id,url}]` arrays. Repeaters preserve JetEngine's associative `item-N` row keys, and unrecognized addon fields are not automatically removed or marked corrupted.

Alerts: `gallery_stored_foreign_host`, `gallery_foreign_host_media`, `gallery_local_file_missing`, `gallery_shared_across_distinct_posts`; and structural errors when explicitly observed. Sharing identical galleries across unrelated posts is a content-review signal, not proof that every photo is wrong. Never automatically overwrite a property/supplier gallery just to clear an alert. Missing images trigger source and license review; an absent file must not be faked by domain rewriting.

One-time site-bound migration scripts are preserved for audit, but are **not** loaded as MU plugins. `wayfa-term-gallery-normalization.php` was applied to six exact Wayfatours destination terms after 89/89 local files passed path validation, with a complete raw metadata backup, compare-and-swap updates and readback. It does not change images, item order, licenses or attachment ownership. It refuses rerun after migration. `wayfa-property-gallery-preview.php` was executed **preview only**; no property galleries were modified, because 19 properties shared an identical gallery and 7 transport records another, requiring a visual and supplier-rights investigation before writes.

Unresolved verified missing files: Aswan City term 2311 has two missing files; Memphis term 2627 has one missing file, absent on BOTH Wayfatours and tours.dev. These require Media Intake asset replacement with geographic/visual/rights review; not cache invalidation or URL rewrite. The governance of gallery additions and repeater subfield edits is separate from scalar `mad4b.media.apply` and remains unsupported until a registered, signed, review-bound composite writer is tested. A refused platform-level tool action is not an internal WordPress capability to bypass.

## Alert grouping, actual storage, and registry validation

`MAD4B_Composite_Media_Integrity_V1::inspect(kind,type,id,field)` reads the registered JetEngine schema, actual effective metadata, and the exact raw meta row independently. It recognizes list galleries, comma-separated URLs, and `[{id,url}]` attachment objects; repeater `item-N` keys and plugin-defined auxiliary fields are preserved. For URL-string galleries, inspect also counts local physical files that do not exist. The provider checks **only non-empty registered fields** through indexed `postmeta`/`termmeta` queries and never executes in a visitor request. A high-volume legacy-domain condition is batched by kind/type/field to avoid flooding Configuration Jobs; genuine missing files still produce per-object alerts. Independently named posts that reuse the exact same gallery (beyond WPML translations) raise one content-quality alert per hash group.

Tests on 2026-11-10: Wayfatours after safe local term-gallery reconciliation generated 12 current signals; tours.dev generated 16. The source has a separate media lifecycle and must not be silently overwritten by the production tenant. Not every identical gallery proves incorrect subject, but it blocks blind bulk normalization or publication without matching each image to the intended supplier/property.
