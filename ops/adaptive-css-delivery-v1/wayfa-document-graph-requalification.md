# V2 Elementor document graph drift requalification (Wayfatours)
The existing 422 consumer rejects changed Elementor document fingerprints without ever changing certificates. The original first-party live CSS drift scanner previously handled only LiteSpeed-v1 bundle changes; V2 DOM change with identical CSS/source generation caused the original queue to retain certified status and never prioritize a new Chromium QA. This change extends that same original scanner, with a strict proof from TWO independent Wayfatours origin FastCGI BYPASS/no-store GETs on the original enrolled WPML URL, same verified market/currency, exact source postid-N or page-id-N body, unchanged original certificate, no V2 styles already applied, exact V2 contract and source-key admission.
Only after matching document fingerprints in those two reads does it create an in-memory shadow selection ledger forcing the original source-family scheduler to retry the original five-viewport browser and CSS integrity QA. No real ledger/certificate/production files are invalidated until original post-release issuance and readback succeed. Negative/unstable evidence stays native.
