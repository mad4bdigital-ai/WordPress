# MAD4B FAORE Spec Kit

Nested Spec Kit workspace for MAD4B Federated Adaptive Operations & Reconciliation Engine, initialized with official Spec Kit CLI v1.2.3 and Codex integration.

The feature is in `specs/001-federated-adaptive-operations` with spec, plan, tasks, model, research, six JSON Schemas and six example events. No runtime implementation is claimed. All tasks are unchecked.

The monorepo root `.specify` belongs to an existing ETG feature and is unchanged. Source Git is deliberately separate from the live PHP container's WordPress document root.
