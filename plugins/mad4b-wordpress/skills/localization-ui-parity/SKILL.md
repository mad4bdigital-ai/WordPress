# MAD4B — Localization Ui Parity

This Skill is company-scoped, advisory and read-first. It does not add WordPress permissions, MCP abilities, payment powers, API secrets or arbitrary shell authority.

## Procedure

1. Enumerate active WPML languages from each enrolled Site Profile; do not hard-code the same translation set across companies.
2. Identify the original Elementor document and translated descendants, query bindings, conditional sections, dynamic widgets, media ownership and canonical style contract.
3. Compare header/menu stacking, floating CTA portal, RTL/LTR, currency switcher, forms/pickups, archives and translated pricing to original source behavior.
4. Detect embedded logo tagline versus separate text, duplicate CTA/price labels, hardcoded 0$, incorrect image resolution, lazy-loading regressions and inaccessible widgets.
5. Use original provider-native controls to repair values; never duplicate a template or use CSS overlays to conceal wrong data ownership.
6. Run targeted Chromium at mobile/tablet/desktop and each affected locale, checking z-index, CLS, visual rendering, broken AJAX links and cache variation.
7. Invalidate only dependencies changed and return per-company/per-language evidence; QA-only snippets are not deployment authority.

## Result contract

Return the exact company/environment, selected native data sources, operation owner, evidence freshness, proposed action, authorization status, verification method and reversible rollback path. Unknowns remain explicit.
