# Daily Cost Components — requirement and source-link layer

Canonical itinerary day keys and source fingerprint are obtained from the existing guide source (including native program term itinerary selection). Tenant-local, tour-scoped `_mad4b_daily_cost_components_v1` records are separated by program ID. Each component has a stable ID, day, dynamic type, label, requirement, inclusion, selection mode, quantity basis/override, tier, source ID, repeater row key, route/notes. No duplicate cost field, new retail price or payment authority. The editor metabox links to a dedicated CRUD page with pricing/edit capabilities, nonce, scope validation, revision/lock and readback. Changed itinerary requires explicit whole-source review; unmatched stale row repair is not yet supported by individual row save.

Native accommodation and guide requirements are delegated to their original providers and not counted again. Registered explicit source references can calculate isolated daily reference lines with existing quantity/FX logic; no native-plus-daily aggregate or approved-price adapter. No guarantee that manual/automatic selection, tiers, inventory and dates are commercially qualified.

Entrance tickets can point directly at a published Attraction or a published Tours & Activities post with exactly tour_mode=activity. The two options are alternatives, not summed. Current existing registry mappings with component key entrance_fee or activity_cost may supply cost candidates; these require review, not automatic admission. Activity start_price is displayed only as an unverified retail reference (no invented currency or procurement price); a verified cost/transfer price and actual service coverage must be established to avoid double margin or duplicate guide/transport. No new attractions or fee values created. Attraction-specific fee authoring, market/date eligibility, approved Activity price resolution and commercial source coverage remain outstanding.

Pilot package 60627: 5 days, 31 requirement rows on each tenant, revision 1; 7 native-delegated (4 overnight, 3 guide), 24 unresolved sources including conditional Colossi of Memnon admission applicability. 23 required-source alerts on each site, no commercial amount or Rate generation. Ground transport, domestic flights, sightseeing tickets, lunches, water and operational assistance are requirements extracted from the canonical itinerary and Includes, not chosen suppliers. No native itinerary text, published Rates, orders or prices altered.
