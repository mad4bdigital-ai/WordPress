# Review-only Tour Media Host Bridge source retention — 20 November 2026

Tours.dev Staging has an active `mad4b-tour-media-host-bridge` optional plugin, whose four classes are loaded from this plugin (confirmed by WordPress ReflectionClass). Wayfatours Production retains corresponding original Media PHP files inside its Control Plane folder and directly `require_once`s them when a signed Host operation is dispatched. The candidate #964 Control Plane intentionally uses `class_exists(..., false)` and returns `mad4b_optional_tour_media_unavailable` when an optional provider is not installed. **No automatic migration or global core loading is authorized.**

This PR preserves the four exact standalone PHP module blobs from Tours.dev and its original plugin entrypoint and test. The only entrypoint modifications are an explicit `Requires PHP: 8.1` header and runtime early-return on unsupported PHP, because these modules use PHP 8 functions such as `str_contains`, `str_starts_with` and `array_is_list`. Both source and target were inspected as PHP 8.5 WordPress containers; these checks do not authorize activation at other sites.

The optional plugin registers only a late-init hook and loads modules when both original signed Host Bridge and the tourism CPT exist; it does not grant Host rights. Internal signed Host grants, site UUID, job/source identities and artifact revision checks remain in the original modules. Plugin activation is separate and must be authorized by a source-controlled release.

**Pre-release requirements:** review 4 PHP module behaviors and tests, validate exact provenance on both sites, run in isolated PHP and disposable WordPress, determine staging/production runtime package readiness, verify Host signed-operation regression and rollback, deploy only via an exact approved plugin update, activate on Wayfatours only with runtime authority, verify equal behavior, then retire the four legacy Control Plane files only after proven non-use. Do not overwrite current WordPress bindings or mail notifications. Zero owner approvals or production rights are inferred.
