# Brand Core: existing document recovery

A missing eligible Brand Core category means missing **approved Registry authority**.
It does not prove absence in the external source. Do not create a duplicate from
that signal or infer consent from a document title or its review-folder location.

Use existing governed paths, without Drive creation or rollback-policy changes:

1. Confirm the installed package identity. PR #455 adds native incident evidence;
   it is not present on the earlier PR #454 source merely because master merged it.
2. Obtain a complete source-scan-plan from the enrolled source. For large sources,
   use its bounded resumable continuation. Keep one cursor until complete.
3. Review external file identity, scope, normalized content hash and inventory.
   Apply through the original exact-plan/source/Registry pins, provider capability
   admission and one-time approval. No guessed receipt or direct SQL ingestion.
4. Verify registered categories and review-queue. Automatic classification is a
   candidate only; correct any ambiguity with the original asset-review path.
5. Obtain a distinct owner decision for each exact current content hash, and
   check Brand Core coverage for conflict, source drift and approved authority.

The convergence plan now routes observed unapproved/unready assets to
`review_or_repair_existing_assets`. It does not run generation evidence collection
when every generatable category is ready, conflicted or already observed. Missing
categories retain the original generation gates and explicitly require an external
existing-document check. This read plan does not register, approve or publish assets.

If planning fails through MCP, inspect Runtime Components → Diagnostics using
#455's existing MU-backed incident journal, or its governed native-runtime-diagnostics
read. Storage failure or no captured incident remains unknown. Neither a Drive
connector read in another client nor the report of a document hash is a substitute
for site-managed source scope, current content readback or provider certification.
