## Company policy (native JetEngine Options Page)

Existing look-and-feel, page ID 192. The native field
tour_rate_facets_display_mode offers:

- adaptive_labels (active default): zero eligible values -> hide; one ->
  a compact non-clickable label; multiple -> retain native JetSmartFilters.
- hide_redundant: hide selectors with zero or one eligible choice
  (legacy behavior).
- always_select: retain native Package and Season Select widgets.

No eligible Rate evidence -> leave the original JetSmartFilter unchanged.
An actively selected query filter -> leave the native select in place.

The mode is scoped to published single Tours and original tour_rates
JetSmartFilters controls. It resolves native filter _query_var and taxonomy
metadata, not Elementor widget element IDs.

related_program_term_id (Select Program) is not covered by this
presentation policy. Its existing JetEngine post-has-terms and original
cruise_tour / Nile cruise program eligibility stay unchanged.
