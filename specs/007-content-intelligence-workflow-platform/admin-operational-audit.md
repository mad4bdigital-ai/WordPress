## Executable coverage

`tests/admin-pages-wordpress.php` runs on real disposable WordPress 6.9/MySQL in
the existing PHP 7.4 and 8.3 Search CI matrix. It compares its page inventory with
the route registry, renders every tab/section with normal and nested-array query
input, checks canonical URLs, checks nonce presence and registered POST actions,
tests direct-renderer permission denial and rejects fabricated success flags.
It also creates a real paused profile through explicit disposable enrollment and
renders every configured Search section. Ordinary views must perform zero HTTP
requests and preserve Site Profile, pipeline settings and write authority.

The profile suite independently verifies exact persistence, disabled/frozen
defaults, registry selection, advanced multi-market policy preservation, stale
revision/rename/security-field denials, explicit state-control fencing/readback,
role/Production/nonce denials and typed navigation. The pipeline suite verifies that checkbox selection preserves stage
policy and remains subject to mandatory stages, trusted registry IDs and CAS.

matching runtime generation and no subject blockers or mutation. That report
explicitly does not authorize release merge. Ability discovery returned MCP
Internal Error, so it did not provide per-page DOM or browser evidence. No browser
fallback was used without the user's approval, and rc.95 installation is not

the setup, save/readback, credential test, endpoint diagnostics and maintenance

notices or labels missing dependencies as successful certification.
