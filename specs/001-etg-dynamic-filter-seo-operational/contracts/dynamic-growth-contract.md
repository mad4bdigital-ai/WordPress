# Dynamic Growth Contract v3

`etg.dfsb.dynamic-growth.v1`

Growth is explicit and monotonic in authority:
`discover → disabled blueprint → exact profile configuration → simulation → readiness → staging evidence → explicit enable`.

Discovery, traffic, crawler demand, generated blueprints, global inheritance, or extension filters never create archive/route authority. Alpha bounds fail visibly rather than silently truncating authority, including bounds exceeded only after extension filters run. If an authority-bearing profile input is truncated or otherwise normalization-invalid, request scope resolution fails closed.
