# Diagnostics Contract v3

`etg.dfsb.decision-trace.v3` includes request path, language, filters, profile ID, scope validity/reason, runtime readiness, provider observation/match, bounded Post Type binding evidence, unsupported query state, combination authority, content readiness, result authority and IndexDecision v3.

Diagnostics exclude full rich term bodies and unbounded galleries. Synthetic Scenario Lab output is separately marked `synthetic=true`.
